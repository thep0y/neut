# 自研/复杂组件用法

这一组页面记录 **shadcn 之外**或 **行为较复杂** 的组件。基础组件（Button、Card、Dialog 等）的
用法与 shadcn 基本一致，见 [组件目录](../components.md)；每个组件的实现取舍见对应目录的 `DESIGN.md`。

| 组件 | 说明 |
| :--- | :--- |
| [Attachment](./attachment.md) | 附件卡片：媒体、标题、描述、操作、上传状态 |
| [Bubble](./bubble.md) | 聊天气泡：对齐、变体、反应 |
| [Marker](./marker.md) | 会话中的系统标记/分隔线 |
| [Message](./message.md) | 单条消息的行布局（头像/内容/头尾） |
| [MessageScroller](./message-scroller.md) | 会话滚动引擎、锚定、spacer、可见性 |
| [Questionnaire](./questionnaire.md) | 多步问卷：答案、校验、快捷键、进度 |
| [Resizable](./resizable.md) | 可调整面板：拖拽、键盘、持久化、命令式句柄 |
| [NumberInput](./number-input.md) | 数字输入：步进、范围、解析/格式化、事件详情 |
| [TimePicker](./time-picker.md) | 时间选择：小时制、步长、列导航 |
| [Calendar](./calendar.md) | 日历：单选/多选/范围、月份下拉、classNames |
| [Combobox](./combobox.md) | 可搜索/多选输入与 listbox |
| [Select](./select.md) | 下拉选择与“选中项对齐”定位 |
| [ContextMenu](./context-menu.md) | 右键菜单、子菜单、typeahead、模态锁滚动 |
| [Toast](./toast.md) | 命令式 toast / promise toast / Toaster |
| [Carousel](./carousel.md) | 轮播：loop、自动播放、键盘、指示点 |
| [Image](./image.md) | `next/image` 风格图片组件 |
| [ScrollArrows](./scroll-arrows.md) | 滚动边缘箭头与悬停滚动 |
| [DataTable](./data-table.md) | 自研 Solid 表格引擎 |
